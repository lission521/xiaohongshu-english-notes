# 小红书英语教学笔记

把真实教材中的一个具体教学问题，做成教师看得懂、能用于备课的小红书图文与打印资料。用户于2026-10-23认可七、八年级样例的整体思路并要求保存此技能；这种认可不等于已试教、已发布或已验证流量效果。

## 开始时

- 先读取本次要求和已有材料，沿用已明确的学科、年级、出版社、学期及修改范围。已有交付先检查，避免重复制作。
- 只有年级时，结合当前会话确定教材范围；不要凭旧知识猜“新版”的单元。版本无法确认而影响内容时，明确询问，同时继续不依赖答案的查找。
- 默认完整交付：一篇文案、7张配图、8页左右A4配套PDF、使用与版本说明、整套ZIP。页数服从教学内容，用户指定数量和局部修改优先；不为凑页数稀释内容。
- 需要参考时，读 [references/approved-examples.md](references/approved-examples.md)，查看其中两张保留封面。学标准，不套原单元事实和固定装饰。
- 完整制作已有授权时，核验、设计、生成、校对、打包连续完成。用户只要思路时先给思路。

## 1. 核对教材，再选切口

- 优先查出版社官方电子教材和配套资源。逐项核对封面、版权信息、目录、课文、任务编号、印刷页码；电子页码另记。只核对目录不能宣称核对正文。
- 官方阅读器不可用时可查公开原教材扫描件，记录镜像来源，用官方目录交叉核验可确认的字段。明确哪个来源支撑正文，不假称已读官方正文。
- 记录书名、册别、单元/篇名、课文页码、URL、核验日期及能确认的审核/版次信息。版权页没有的印次、ISBN、时间不要补猜；文件名和网站“新版”标签不是证据。
- 同名课文、旧教材和教辅可能有不同人物、方位、任务编号。以实际页面为准，不混版本。先建立准确内容提纲和任务对照，再写教案与提示词。
- 选一个具体问题，如“校园介绍只会写beautiful”“圈出形容词后怎样解释证据”。标题体现年级/单元、教师痛点和可得到的支架；避免空泛“高效课堂”和无依据成效承诺。
- 用户要求后台复盘时，先刷新可访问的后台数据，区分观察、推测与待验证假设。旧快照不当实时数据；后台分析不作为每次制作的强制前置条件。

## 2. 把教学内容做实

- 写清使用场景：对应哪一课、学生完成什么、教师如何组织、留下什么产出。
- 区分教材原任务、原创支架、自编示例、外部补充资料。新增表格、问题链、例句不能冒充教材原活动。
- 流程包含时长、教师提问/指令、学生行动、可检查产出。45分钟作参考，内容过多说明哪些后续完成，不强塞整单元。
- 开放任务给参考角度或评价标准，容纳合理答案；虚构学校/人物/例段标为自编，提醒换成真实情况。
- 不编课堂照片、学生作品、原话、试教经历、成绩变化或保护成效。未试教用“教学建议”，不写“我这样上，学生立刻就会”。
- 教材设想不写成真实事件；事实、解释、建议分开。数字和拓展知识保留来源与范围，不放大教材表述，不用未经核实知识填段落。
- 文案有具体做法、可用示例和自然交流问题，标签相关。避免堆术语、夸张承诺、空泛引流。

## 3. 每篇选择艺术方向

- 每篇明确与主题相合的艺术语言、主辅色和信息结构。同篇统一，相邻篇主动变化。
- 可从建筑速写、植物版画、新艺术运动、包豪斯、构成主义、拼贴、木刻、水彩、民艺等选择；艺术服务内容，避免只换色仍重复同一版式。
- 封面有清楚大标题、教学用途和视觉信息。结合真实教材局部、步骤、表格、信息链或对比，让读者知道能得到什么。
- 装饰集中边缘和重点，正文留足空间。中文清楚、层级明确、对比充足，避免细小密字、重复卡片和装饰压字。可以有备课纸张/印刷质感，不伪造现场。
- 默认竖版3:4系列，检查实际比例；需要统一时保全内容，不裁断文字。未检查不宣称尺寸一致。
- 7图可参考：封面、教材依据、内容结构、核心支架、课堂流程、示例/评价、配套资料；随任务调整。

## 4. 整页生图与真实教材

- 使用当前可用的内置 image_gen；先读取可用的 imagegen 技能。不虚称模型版本，不以脚本绘图替代整页生图。
- 每页提示词锁定文字、版式、配色、艺术方向、图示逻辑、页码及事实限制。中英文逐项校对，内页不重复塞封面。
- **教材用真实原图局部，不让图像模型重画。** 预留空白区，将真实裁片无改字嵌入。确定性裁切/缩放/嵌入仅用于素材保真，不代替整页设计或重新叠正文。记录来源页、裁切框和位置，验收嵌入后的最终图。
- 只引用说明教学依据所需的局部，不把完整教材PDF打进发布包。装饰插画明确为设计示意。
- 逐张目视检查汉字、拼写、编号、图表关系、页码与裁片边缘。错误用生图工具局部修改或重生成对应页，保留正确页；持续失败时保留已完成内容并准确说明缺项，不无限重试。

## 5. 配套PDF能打印和使用

- 创建或修改PDF时读取可用的 pdf 技能，遵循其制作、渲染和交付要求。使用可提取文字与清楚表格，不把小红书长图直接缩印成任务单。
- PDF和图文共用核验内容；流程、板书、示例、学生任务一致。学生页留足手写空间，明确实际打印页码。
- 认可样例的8页结构可参考：1目标范围、2流程、3板书支架、4示例评价、5—7学生任务、8来源版本。新选题可调整，不机械套页。
- 示例答案、评价标准和独立检查任务对应学习目标，能检查定位事实、解释或表达，不只机械填空。
- 渲染每页检查缺字、截断、分页、字号、边距、表格和留白；文字提取仅辅助。修改后重查受影响部分及必要完整性。

## 6. 交付与修改

- 遵守项目AGENTS.md。原始资料、过程稿、最终文件分开；修改草稿留临时目录。正式交付清楚命名，避免“最终版2”并存。
- 默认目录：有序7张PNG、配套PDF、笔记文案.txt、使用与版本说明.txt、配图提示词.txt。ZIP仅含交付文件；原教材、QA预览和过程稿不混入上传素材。
- 说明写清来源与核验范围、自编部分、学生打印页、插画性质及完成状态；不夸大试教、实物打印或发布的验证程度。
- 检查文件数、ZIP完整性和路径；展示封面/少量代表预览，给整套入口及PDF技能要求的直接入口。
- 局部修改只改指定内容并检查其它部分，避免每次复制整套正式稿。
- 仅用户明确“定稿”后按项目规则清理替代稿，优先移入废纸篓并报告。原始资料、用途不明、其它项目、依赖素材不自动清理；未清空废纸篓只说待释放空间。
- 调用本技能不代表授权发布、私信、外部分享、更新全局记忆或修改技能自身；这些操作依其用户授权执行。
